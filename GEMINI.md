# GraphMind Project Instructions

Refer to [AGENTS.md](./AGENTS.md) for full collaboration rules, workflow, and standards.

## Core Rules:
1. **Pick One Task at a Time**: Work sequentially according to [`docs/phases/`](./docs/phases/).
2. **Explain & Discuss First**: Explain the task and agree on implementation design with the user before writing code.
3. **Hard Approval Gate**: Wait for user confirmation before making file modifications.
4. **Zero Dead UI**: Only build functional features matching the active milestone.
