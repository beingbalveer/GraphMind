Begin with the learner's stated outcome and existing knowledge. Preserve a supplied title.
Use meaningful phases and only the groups needed to make the path understandable.
Separate containment, prerequisites, alternatives, and presentation order. Keep shared
prerequisites outside mutually exclusive choices; select one viable alternative initially.

Each actionable topic has a concise purpose, measurable objectives, a practical exercise,
an honest effort estimate, and relevant verified resources. Include practice, projects,
and review time. Further-learning overview topics still have actionable briefs and
resources. Never use empty containers or placeholder lessons as a substitute for coverage.

Keep a realistic coherent core and put additional breadth in further-learning branches.
State the actual achievable outcome when the requested ambition exceeds the budget.
Respect at most 200 actionable topics and six hierarchy levels; narrow transparently.
Do not use a fixed domain phase list for unrelated subjects. Explain necessary assumptions,
and ask only when the missing answer materially changes the curriculum.

Run structure and workload checks after composition and after every repair. Address concrete
validation issues; a valid graph alone does not establish educational quality or coverage.
Retain stable IDs during refinement, including unchanged topics and shared prerequisites.
