## 1. Executive Summary & Objective

In accordance with [LSI-003](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-003-port-production-shell-into-next), the Learning Studio shell layout, persistent rails, and responsive contextual drawers have been ported into GraphMind's production Next.js App Router (`apps/web/src`).

All components adhere strictly to the repository's design system standards ([AGENTS.md](file:///Users/balveerd/Documents/AI/GraphMind/AGENTS.md) §5), including semantic design tokens (`bg-background`, `bg-surface`, `text-foreground`, `border-border`), `@/components/ui/` primitives (`Button`, `Drawer`, `Badge`, `SegmentedTabs`), and standard header dimensions (`h-13` / 52px). The ported shell is isolated behind a gated internal preview route (`/studio-preview`) to prevent exposing un-wired controls to production users while backend integration proceeds.

### 2.1 Component Specifications
1. **`LearningStudioShell` (`apps/web/src/components/studio/LearningStudioShell.tsx`):**
   - Implements a flexible 3-column desktop layout (`Left Course Rail` + `Center Stage` + `Right Tutor Rail`).
   - Automatically collapses rails into accessible `<Drawer>` overlays on constrained viewports (<1024px).
   - Listens to Escape key for accessible drawer dismissal on mobile/tablet viewports.
   - Prevents double mounting or duplicate chat containers.
2. **`StudioHeader` (`apps/web/src/components/studio/StudioHeader.tsx`):**
   - Standardized `h-13` (52px / 3.25rem) height.
   - Houses GraphMind brand badge, course title indicator, primary navigation pills (`Home`, `My Learning`, `Browse`, `Create`), and theme toggle.
3. **`StudioCourseRail` (`apps/web/src/components/studio/StudioCourseRail.tsx`):**
   - Course progress bar with accessible `progressbar` semantics.
   - Segmented tab switching between course outline (topics list) and course conversations.
4. **`StudioTutorRail` (`apps/web/src/components/studio/StudioTutorRail.tsx`):**
   - Right rail supporting expand/collapse transitions (`w-80` to `w-[440px]`).
   - Tab switching between interactive AI Tutor companion and lesson references/sources.
5. **Gated Internal Route (`apps/web/src/app/studio-preview/page.tsx`):**
   - Mounts the shell with mock topics and realistic layout state for end-to-end rendering verification.
