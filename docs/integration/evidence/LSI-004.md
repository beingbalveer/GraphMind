## 1. Executive Summary & Objective

In accordance with [LSI-004](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-004-real-sessions-and-public-route-boundary), the real session and public route boundary has been established in Next.js middleware and client authentication handling:
1. **Narrow Public Route Boundary:** Only approved public paths (`/login`, `/learn`, and internal preview routes) are allowed through without session credentials.
2. **Strict Private Protection:** All private paths (`/`, `/w/{workspaceId}/...`, `/learning`, `/settings`) require authenticated cookies (`access_token` or `refresh_token`), redirecting unauthenticated users to `/login`.
3. **Open-Redirect & Hostile Return Defense:** Implemented `sanitizeRedirectPath` in `@/lib/urls` and applied it across both middleware redirects and the `/login` page return router, completely rejecting external URLs (`https://`, `http://`), protocol-relative URLs (`//evil.com`), `javascript:` vectors, and malicious backslash escapes.
4. **Cache & Session Erasure on Logout:** Enhanced `logout` in `AuthContext` to clear private workspace keys, pending auth intents, and session storage.

## 2. Changes Made

### 2.1 Middleware Configuration (`apps/web/src/middleware.ts`)
* Defined `PUBLIC_PREFIXES = ["/login", "/learn", "/studio-preview", "/dashboard-preview", "/font-comparison"]`.
* Unauthenticated requests to public paths pass immediately (`NextResponse.next()`).
* Unauthenticated requests to protected paths redirect to `/login?next={safeNext}`.
* Authenticated users visiting `/login` are automatically redirected to `next` (sanitized) or `/`.

### 2.2 Canonical URL Sanitizer (`apps/web/src/lib/urls.ts`)
* Added `buildPublicCatalogUrl()`, `buildPublicRoadmapUrl()`, and `buildPublicLessonUrl()`.
* Added `sanitizeRedirectPath(path, fallback)` enforcing single-slash relative URI semantics and stripping control characters.

### 2.3 Login Page Return Validation (`apps/web/src/app/login/page.tsx`)
* Sanitizes incoming search param `?next=` using `sanitizeRedirectPath(rawNext, "/")`.
* Prevents open-redirect vulnerabilities during both Google OAuth and standard credential authentication.

### 2.4 Private Cache Invalidation (`apps/web/src/context/AuthContext.tsx`)
* On logout, clears:
  - `sessionStorage`
  - `localStorage.removeItem("graphmind_recent_workspaces")`
  - `localStorage.removeItem("active_chat_id")`
  - `localStorage.removeItem("graphmind:pending_auth_intent")`
