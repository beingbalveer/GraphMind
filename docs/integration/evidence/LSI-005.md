## 1. Executive Summary & Objective

In accordance with [LSI-005](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-005-authorized-collection-summaries), authorized collection summaries have been implemented across the backend API and web client layers:
1. **Curriculum Projection on Workspaces (`WorkspaceCurriculumSummary`):** Extended `WorkspaceResponse` and `WorkspaceItem` with an optional `curriculum` summary field. For workspaces with associated roadmaps, this projects curriculum metadata (roadmap ID, revision ID, title, status, topic count, completed topics, progress percentage, and source snapshot reference).
2. **Optimized Batch Resolution:** Implemented batch querying in `WorkspaceService.list_workspaces` for associated `Roadmap`, `CurriculumRevision`, and learner-scoped `TopicProgress` records. This ensures zero N+1 database roundtrips and zero cross-user metadata leaks.
3. **Dedicated Learning Roadmaps Endpoint:** Implemented `GET /api/v1/workspaces/{workspace_id}/learning-roadmaps` guarded by `require_roadmap_read` and `get_roadmap_user`, strictly preventing anonymous access (401) and cross-tenant leakage (404/403).
4. **Typed Web Client Integration:** Updated `@/lib/workspaceApi` with `WorkspaceCurriculumSummary`, updated `WorkspaceItem`, and added `fetchWorkspaceCurricula`.

## 2. Changes Made

### 2.1 Backend Schemas (`apps/api/src/schemas/workspace.py`)
* Defined `WorkspaceCurriculumSummary(BaseSchema)`:
  - `roadmap_id: str`
  - `revision_id: Optional[str] = None`
  - `title: str`
  - `status: str = "active"`
  - `total_topics: int = 0`
  - `completed_topics: int = 0`
  - `progress_percent: float = 0.0`
  - `source_snapshot_ref: Optional[str] = None`
  - `origin_job_id: Optional[str] = None`
  - `updated_at: Optional[datetime] = None`
* Added `curriculum: Optional[WorkspaceCurriculumSummary] = Field(default=None)` to `WorkspaceResponse`.

### 2.2 Workspace Service Batch Projections (`apps/api/src/services/workspace_service.py`)
* In `WorkspaceService.list_workspaces`, batch-fetches roadmaps, revisions, active topic counts, and user completion progress across all returned workspaces.
* Implemented `WorkspaceService.get_workspace_curricula(session, workspace_id, user_id)` for single-workspace curriculum summary queries.

### 2.3 Router Endpoint (`apps/api/src/routers/workspaces.py`)
* Added `GET /api/v1/workspaces/{workspace_id}/learning-roadmaps`.
* Bound to `require_roadmap_read` and `get_roadmap_user` dependencies.

### 2.4 Web Client (`apps/web/src/lib/workspaceApi.ts`)
* Exported `WorkspaceCurriculumSummary` interface matching server camelCase projection.
* Added `curriculum?: WorkspaceCurriculumSummary | null` to `WorkspaceItem`.
* Exported `fetchWorkspaceCurricula(workspaceId: string): Promise<WorkspaceCurriculumSummary[]>`.
