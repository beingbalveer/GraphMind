## 1. Executive Summary & Objective

In accordance with [LSI-006](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-006-home-and-my-learning), the learner entry points (`Home` and `My Learning`) have been implemented in production Next.js with authorized collection summaries:
1. **Authorized Collection Summaries Integration:** Connected learner views to server collection summaries (`WorkspaceItem` with `WorkspaceCurriculumSummary` projection) instead of prototype localStorage.
2. **Production `StudioHomeView`:**
   - Detects active enrolled roadmaps and presents authoritative progress (`{done}/{count} lessons`, percent progress bar, and dynamic badges `"IN PROGRESS"` vs `"PATH COMPLETE"`).
   - Dynamically adapts button between `"Continue learning"` and `"Review lessons"` with `onResume(workspaceId)` action.
   - Graceful loading skeletons, error banner with retry trigger, and empty state with browse/create actions.
3. **Production `StudioMyLearningView`:**
   - Displays multiple personal copies as distinct cards with independent identities (even when sharing the same template/origin reference).
   - Authoritative topic counts and category badges (`Snapshot`, `Generated`, `Personal`).
   - Interactive search bar matching titles and descriptions.
   - Tab-based progress filtering (`All`, `Not started`, `In progress`, `Completed`).
   - "Clear search and filters" when query yields no results, or "Browse roadmaps" when no roadmaps exist.
4. **Hook Integration (`useAuthorizedCurricula`):** Encapsulates fetching, error states, and selection of the most recently updated active curriculum workspace.
5. **Interactive Preview Integration:** Wired both views into `/studio-preview` with mode switching between Home, My Learning, and active course lesson stage.

## 2. Changes Made

### 2.1 Hook (`apps/web/src/components/studio/useAuthorizedCurricula.ts`)
* Exports `useAuthorizedCurricula(initialWorkspaces?)` providing:
  - `workspaces: WorkspaceItem[]`
  - `learningWorkspaces: WorkspaceItem[]`
  - `activeLearningWorkspace: WorkspaceItem | null`
  - `isLoading: boolean`
  - `error: string | null`
  - `refresh: () => Promise<void>`

### 2.2 Home View (`apps/web/src/components/studio/StudioHomeView.tsx`)
* Implements `StudioHomeView` strictly using `@/components/ui/` primitives (`Button`, `Badge`) and semantic design tokens.
* Renders active learning curriculum card, authoritative progress bar, and "Build a focused plan" action card.

### 2.3 My Learning View (`apps/web/src/components/studio/StudioMyLearningView.tsx`)
* Implements `StudioMyLearningView` using `Input`, `SegmentedTabs`, `Button`, and `Badge`.
* Supports keyword search, 4-state progress tab filtering, authoritative counts, and distinct card identities.

### 2.4 Preview Route (`apps/web/src/app/studio-preview/page.tsx`)
* Integrates `StudioHomeView` and `StudioMyLearningView` into the center stage when navigating to `home` and `learning`.

### 2.5 Unit Test Suite (`apps/web/src/components/studio/__tests__/StudioLearnerViews.test.tsx`)
* 9 comprehensive unit tests covering:
  - Loading skeleton states.
  - Error banner rendering and retry triggers.
  - Empty collection states and browse/create handlers.
  - Picking the most recently updated active roadmap with authoritative counts.
  - Completed roadmap presentation (`"PATH COMPLETE"`).
  - Multiple distinct copies rendered independently without collision.
  - Keyword search filtering.
  - Tab progress filtering (`not-started`, `in-progress`, `completed`).
  - Search clearing and filter reset.
