## 1. Executive Summary & Objective

In accordance with [LSI-007](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-007-private-roadmap-outline), the private course outline and full roadmap list views have been implemented in production Next.js:
1. **Production `StudioCourseOutline` (Left Rail Outline):**
   - Renders curriculum phases and child topics grouped hierarchically from `CurriculumView` graph data (`relations` of type `"contains"` or order fallback).
   - Authoritative completion state via checkmarks (`CheckCircle2` for completed topics vs `Circle` for pending).
   - Clear active topic highlight state (`bg-surface-hover text-foreground font-medium`).
   - Duration estimation pills (`{estimateMinutes}m`).
   - Empty/loading states gracefully handled.
2. **Production `StudioCourseListView` (Full Course Stage List View):**
   - Full-stage structured curriculum breakdown displaying phases, brief summaries, and nested topic cards.
   - Rich topic metadata: format badges (`concepts`, `practice`, `project`, `review`), learning objectives, practice exercises, and source references.
   - Direct click-to-select topic handlers triggering navigation to lesson reader.
   - Ordinary workspace degradation: when a workspace does not have a learning roadmap attached (`ROADMAP_NOT_FOUND`), renders a clean empty state card ("No curriculum roadmap attached") rather than erroring or crashing.
3. **Interactive Preview Integration:**
   - Wired `StudioCourseOutline` into `StudioCourseRail`'s `outlineContent` slot in `apps/web/src/app/studio-preview/page.tsx`.
   - Wired `StudioCourseListView` toggleable via "Roadmap Outline" header action on the lesson stage.
4. **Design System & Type Strictness:**
   - Adheres strictly to [AGENTS.md](file:///Users/balveerd/Documents/AI/GraphMind/AGENTS.md) design tokens (`bg-surface`, `text-foreground`, `border-border`, `text-success`) and `@/components/ui/` primitives (`Button`, `Badge`).

## 2. Changes Made

### 2.1 Course Rail Outline (`apps/web/src/components/studio/StudioCourseOutline.tsx`)
* Implements `StudioCourseOutline` component:
  - Extracts phases and child topics from `CurriculumView.candidate.items` and `relations`.
  - Renders compact phase section headers and topic navigation buttons.
  - Highlights active topic selection with callback `onSelectTopic(topicId)`.

### 2.2 Full Course List View (`apps/web/src/components/studio/StudioCourseListView.tsx`)
* Implements `StudioCourseListView` component:
  - Renders full curriculum hierarchy with phase overviews and detailed topic cards.
  - Displays format badges, estimate duration, objectives, exercises, and linked source provenance.
  - Gracefully handles missing roadmap (`view === null`) with clean informative UI.

### 2.3 Studio Preview Integration (`apps/web/src/app/studio-preview/page.tsx`)
* Replaces inline mock topics in rail with `StudioCourseOutline`.
* Adds full stage toggle for `StudioCourseListView`.

### 2.4 Unit Test Suite (`apps/web/src/components/studio/__tests__/StudioRoadmapOutline.test.tsx`)
* 6 comprehensive unit tests covering:
  - Outline rendering with hierarchical phases and topics.
  - Active topic styling and selection callback.
  - Completion status checkmarks based on `view.progress`.
  - Empty state handling when view is null.
  - Full course list view rendering with phases, objectives, exercises, and sources.
  - Ordinary workspace degradation without error throwing.
