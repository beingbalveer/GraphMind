## 1. Executive Summary & Objective

In accordance with [LSI-008](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-008-persistent-lesson-reader-and-sources), the persistent lesson reader and verified reference sources experience has been implemented across backend and frontend:
1. **Lesson Content Resolution Lifecycle (Three Tiers):**
   - **Tier 1 (Authored Content):** When `CurriculumItemData.content_markdown` is present, renders authored markdown with styled typography, headings, and code blocks.
   - **Tier 2 (Server Saved Assistant Lesson):** When a tutoring session produced a completed lesson node (`f"{default_chat_id}_lesson"` in `NodeModel`), `CurriculumRepository.read_brief` resolves and returns `saved_lesson_content` on `TopicBrief`.
   - **Tier 3 (Honest Brief State):** When neither is present, renders an honest, non-presumptuous brief state containing the topic's learning objectives, reflection exercise prompt, and notice explaining that the full lesson has not yet been generated. Reading does not implicitly create a chat session or start an LLM stream.
2. **Verified Reference Sources & Citations:**
   - Displays external reference sources with Title, clickable URL / locator string, verification badge (`grounded`, `inspected`, `unavailable`), access badge (`free`, `paid`), kind tag, and expandable locator excerpts.
3. **Passage Text Selection & Quote Capture:**
   - Highlights in `[data-lesson-content]` can be captured via "Ask about selected passage" to quote directly in tutor discussion. Non-lesson elements (reflection controls, sources, buttons) are excluded with a helpful guidance message.
4. **Reading Position Persistence:**
   - Client storage helper `useReadingPosition` throttles and saves `{ scrollRatio, scrollY }` scoped to `graphmind:reading_pos:${workspaceId}:${topicId}`.
   - Restores scroll position smoothly upon mount or mobile refresh with a subtle "Resumed reading position" indicator.
5. **Stage & Outline Integration:**
   - Wired `StudioLessonReader` into `/studio-preview` with lesson navigation (Previous / Continue to next lesson), breadcrumb navigation back to full roadmap outline, and interactive completion toggle.

## 2. Changes Made

### 2.1 Backend Schema & Repository Extensions
* `apps/api/src/schemas/curriculum.py`:
  - Added `content_markdown: str | None = Field(default=None, max_length=65536)` to `CurriculumItemData`.
  - Added `saved_lesson_content: str | None = None` to `TopicBrief`.
* `apps/api/src/services/roadmap/curriculum_repository.py`:
  - Extended `read_brief` to check `NodeModel` for `f"{default_chat}_lesson"` and populate `saved_lesson_content`.

### 2.2 Frontend Types & Storage Utilities
* `apps/web/src/lib/roadmapTypes.ts`:
  - Added `contentMarkdown?: string | null` to `CurriculumItemData`.
  - Added `savedLessonContent?: string | null` to `TopicBrief`.
* `apps/web/src/lib/readingPosition.ts`:
  - Implemented scoped storage helpers `getReadingPosition`, `saveReadingPosition`, `clearReadingPosition`, and `useReadingPosition` hook.

### 2.3 Production Lesson Reader Component
* `apps/web/src/components/studio/StudioLessonReader.tsx`:
  - Three-tiered content resolution rendering.
  - Verified sources card grid with status badges and excerpt accordion.
  - Passage selection and quote capture with validation.
  - Reading position restoration.
  - Previous / next lesson navigation and completion toggle.
* `apps/web/src/app/studio-preview/page.tsx`:
  - Replaced hardcoded stage with `StudioLessonReader`.
  - Wired interactive topic switching, completion state, and outline toggles.
