## 1. Executive Summary & Objective

In accordance with [LSI-011](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-011-practice-ui), the Practice UI has been integrated into the Learning Studio reader using GraphMind's production-grade design system and the versioned server contract established in LSI-010:
1. **Interactive Versioned Practice Activity (`StudioPracticeActivity`):**
   - Renders real server-provided activities: multiple-choice (`choice`), short-answer questions (`short_answer`), and reflections (`reflection`).
   - Choice questions render as accessible radio groups with full keyboard navigation and selection state.
   - Short answer and reflection questions render using `@/components/ui/textarea` with auto-growing input.
2. **Owned Draft Persistence:**
   - On mount, fetches learner's saved draft via `readTopicPracticeState`.
   - Debounced auto-save (600ms) syncs user input to `PUT /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks/draft` with visual status indicators ("Saving draft...", "Draft saved").
   - "Start over" action calls `DELETE /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks/draft` and clears local form state.
3. **Validated Feedback & Retries:**
   - Attempt submission calls `POST /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks` with unique attempt ID, version tags, and learner answer/choice.
   - Constructive feedback and detailed explanations are announced in an accessible container with `role="status"` and `aria-live="polite"`.
   - Distinguishes success (`border-success/40 bg-success/10`), review/retry needed (`border-warning/40 bg-warning/10`), and saved reflection (`border-primary/40 bg-primary/10`).
   - Dynamic attempt counter badge tracks cumulative attempts for the learner.
4. **Hint Disclosure:**
   - Interactive disclosure toggle with `<Lightbulb>` and `aria-expanded` reveals `activity.hint`.
5. **Anti-Mastery & Completion Decoupling:**
   - Submitting an attempt never mutates topic progress or calls completion endpoints.
   - Explicit anti-mastery disclaimer: "Practice checks are self-directed exercises for reinforcement. Submitting an answer does not automatically complete the topic or infer mastery."
6. **Honest Empty & Gated States:**
   - Unconfigured or missing activity displays an honest empty state without broken UI.
   - Un-enrolled/guest state gracefully presents locked banner with `onEnablePractice` trigger.

## 2. Changes Made

### 2.1 API Client Extensions (`apps/web/src/lib/roadmapApi.ts`)
* Added `readTopicPracticeState`: `GET /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks`
* Added `savePracticeDraft`: `PUT /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks/draft`
* Added `deletePracticeDraft`: `DELETE /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks/draft`
* Added `submitPracticeAttempt`: `POST /workspaces/{workspace_id}/roadmap/topics/{topic_id}/checks`
* Exported new practice types in `apps/web/src/lib/roadmapTypes.ts`.

### 2.2 Interactive Practice Component (`apps/web/src/components/studio/StudioPracticeActivity.tsx`)
* Implemented `StudioPracticeActivity`:
  - Uses `@/components/ui/button`, `@/components/ui/badge`, `@/components/ui/textarea`.
  - Adheres strictly to design tokens (`bg-surface`, `border-border-subtle`, `text-foreground`, etc.).
  - Supports choice, short-answer, and reflection formats.
  - Implements hint toggle, attempt counter, attempt history, debounced draft saving, reset, and retry.
  - Handles server 422 activity version mismatch by automatically refreshing the active practice activity.

### 2.3 Lesson Reader Integration (`apps/web/src/components/studio/StudioLessonReader.tsx`)
* Mounted `<StudioPracticeActivity>` beneath the reflection section.
* Maintained backward compatibility with static conceptual exercises while providing interactive practice checks.

### 2.4 Unit Test Suite (`apps/web/src/components/studio/__tests__/StudioPracticeActivity.test.tsx`)
* 7 thorough unit tests verifying:
  1. Choice activity loading and hint toggle (`aria-expanded`).
  2. Choice selection and attempt submission with `role="status"` feedback display.
  3. Short-answer draft loading and debounced draft auto-save.
  4. Retry workflow and "Start over" draft deletion.
  5. Honest empty state when activity is unconfigured.
  6. Locked state when enabled is false and `onEnablePractice` invocation.
  7. Decoupling and anti-mastery disclaimer presence.

## 4. Acceptance Criteria Checklist

- [x] **Render real activities**: Supports server-backed `choice`, `short_answer`, and `reflection` activities.
- [x] **Validated feedback & hints**: Feedback announced via `role="status"` and `aria-live="polite"`; hint toggle with `aria-expanded`.
- [x] **Retries & start over**: Resets state, clears drafts, and supports continuous attempt progression with attempt counters.
- [x] **Owned answer drafts**: Debounced draft auto-save and draft deletion via dedicated API endpoints.
- [x] **Missing activities have honest state**: Displays clear unconfigured banner rather than mock fallbacks or broken UI.
- [x] **No automatic completion/mastery**: Practice submissions never trigger progress state changes or mastery claims.
- [x] **Design system compliance**: Uses `@/components/ui/` primitives (`Button`, `Badge`, `Textarea`), semantic color tokens, and strict sizing.
