## 1. Executive Summary & Objective

In accordance with [LSI-012](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-012-shared-roadmap-and-conversation-canvas), the roadmap canvas and spatial navigation capabilities have been unified between the core GraphMind canvas architecture and the Learning Studio:
1. **Reuse Existing Canvas Renderer (`RoadmapCanvas`):**
   - The Learning Studio course view reuses GraphMind's existing `RoadmapCanvas` component, preserving zoom/pan navigation, 2D node placement, level/status badges, and topic selection callbacks.
   - Preserves curriculum projection logic from `curriculumProjection.ts`, ensuring 100% projection parity between the phased outline list and the spatial canvas.
2. **Guest / Public Read-Only Layout Protection:**
   - In read-only mode (guest readers or views with `readOnly: true` / `!view.canWrite`), `RoadmapCanvas` disables layout persistence by passing `undefined` for `workspaceId` and `chatId` to `useCanvasLayout`.
   - Prevents unauthorized callers from hitting private authenticated layout endpoints (`/api/v1/workspaces/{id}/canvas-layout`).
   - Replaces mutation callbacks (`onLayoutChange`) with a no-op handler in read-only mode.
3. **Phased List & Spatial Canvas View Mode Switching:**
   - Integrated `<SegmentedTabs>` into `StudioCourseListView` allowing learners to switch between `list` (phased outline) and `canvas` (2D spatial canvas).
   - Both modes share identical curriculum items, topic metadata, and selection behaviors.
4. **Canonical URL Contract Alignment:**
   - Aligned with GraphMind's non-negotiable URL contract:
     - Phased outline / curriculum page: `/w/{workspaceId}`
     - 2D spatial canvas: `/w/{workspaceId}/chat/{view.canvasAnchorChatId}/canvas` (constructed via `buildCanvasUrl(workspaceId, canvasAnchorChatId)`)
   - `roadmapRouteMode` helper cleanly maps pathnames to `"page"` vs `"canvas"`.

## 2. Changes Made

### 2.1 Canvas Guest & Read-Only Guard (`apps/web/src/components/roadmap/RoadmapCanvas.tsx`)
* Added `readOnly?: boolean` prop to `RoadmapCanvasProps`.
* Conditionally guarded `useCanvasLayout`:
  ```tsx
  const isReadOnly = readOnly ?? !view.canWrite;
  const stored = useCanvasLayout(
    isReadOnly ? undefined : view.workspaceId,
    isReadOnly ? undefined : view.canvasAnchorChatId,
    "curriculum"
  );
  ```
* Guarded `onLayoutChange` on `<CanvasSurface>` to prevent mutations when `isReadOnly` is true.

### 2.2 Studio Course List View Mode Switcher (`apps/web/src/components/studio/StudioCourseListView.tsx`)
* Added `mode?: "list" | "canvas"` and `onModeChange?: (mode: "list" | "canvas") => void` props.
* Added `<SegmentedTabs>` control in header allowing seamless switching between Phased Outline and 2D Spatial Canvas.
* Embedded `<RoadmapCanvas>` within an accessible, bordered container when `canvas` mode is selected.

### 2.3 Studio Preview Updates (`apps/web/src/app/studio-preview/page.tsx`)
* Updated the prototype harness to support testing and previewing both `list` and `canvas` modes.

### 2.4 Unit Test Suite (`apps/web/src/components/studio/__tests__/StudioRoadmapCanvas.test.tsx`)
* Created comprehensive test suite verifying:
  - Canonical URL routing contract for list vs canvas view mode (`roadmapRouteMode`).
  - Rendering and projection parity across list and canvas modes.
  - Mode switching between outline list and canvas tabs.
  - Guest/read-only layout protection (verifying `useCanvasLayout` is invoked with `undefined` when `readOnly` is true).
  - Topic selection forwarding from canvas cards to course handler.
  - Omission of protected anchor chat IDs when in guest/read-only mode.
