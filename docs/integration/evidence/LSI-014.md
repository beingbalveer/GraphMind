## 1. Executive Summary & Objective

In accordance with [LSI-014](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-014-tutor-stream-and-local-context-lifecycle), the AI Tutor stream and local context lifecycle have been integrated into the Learning Studio companion pane:
1. **Existing SSE Stream Integration (`StudioTutorChat`):**
   - Connects to existing `/api/v1/chat/stream` SSE protocol via `useChatStream()`.
   - Binds every stream request to the authenticated workspace and saved topic session (`workspaceId`, `topicSessionId`, `parent_node_id`).
   - Injects contextual system prompt orienting the AI tutor to the specific active lesson topic.
2. **Scoped Composer, Quoted Passage, & Draft Persistence:**
   - Composer drafts are safely persisted to `localStorage` under topic-session scoped keys (`graphmind_studio_tutor_draft_{workspaceId}_{sessionId || topicId}`).
   - Switching topics or sessions swaps drafts cleanly without cross-contamination.
   - Quote context banner displays highlighted text selected in the lesson reader with clear/remove action.
   - Sending a message transmits the quote context (via prompt formatting and `branchOverride.highlightedText`) and clears both the quote banner and draft upon submission.
3. **Stop & Retry Controls:**
   - Active generation surfaces a prominent "Stop" button that calls `stopStreaming()`, aborting network transport and marking the stream stopped.
   - Retryable assistant messages (failed, interrupted, or containing error notices) surface a "Retry" button.
   - Calling `retryLastMessage()` seamlessly reuses the user parent message and updates the assistant response without appending duplicate assistant nodes.
4. **Interruption Recovery & Late-Output Protection:**
   - On topic switch, session switch, or unmount, any active stream is immediately aborted via `stopStreaming()`.
   - Maintained scope tracking (`activeScopeRef`) so any late-arriving SSE chunks or delayed fetch responses from a prior topic cannot contaminate the current pane.
   - Auto-scrolls smoothly to new tokens only if supported in the runtime environment.
5. **Empty State & Guided Prompts:**
   - If no messages exist yet in the session, renders an inviting AI Tutor card with topic summary and quick clickable question chips ("Summarize key ideas", "Show a practical code example", "What are common pitfalls?").
