## 1. Executive Summary & Objective

In accordance with [LSI-015](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-015-branch-service-integrity), backend branch creation, ancestry verification, and conversational lineage authorization have been comprehensively strengthened:

1. **Rejection of Cross-Workspace Origins:**
   - In `WorkspaceService.add_node_and_edge`, passing a `parent_id` belonging to a foreign workspace or non-existent record previously fell back to `parent_id = None` (which silently converted branches into disconnected chat roots).
   - Now, foreign or missing parent origins are strictly rejected with `HTTP 404 Not Found`.
   - In `/api/v1/chat/stream` and `/api/v1/chat/completions`, requests referencing `parent_node_id` in a foreign workspace or non-existent record are strictly rejected with `HTTP 404 Not Found`.

2. **Cycle Prevention & Ancestry Traversal:**
   - Self-loop cycles (`data.id == data.parent_id`) are rejected immediately with `HTTP 422 Unprocessable Content`.
   - Before attaching or re-parenting a node, the server traverses the parent lineage up to the root. If `data.id` is encountered along the ancestor path, the request is rejected with `HTTP 422 Unprocessable Content` ("Cycle detected: cannot set parent to a descendant node").
   - Traversal depth bounds and loop detection guarantee termination and prevent infinite loops.
   - In `ai_core.lineage.get_ancestor_nodes`, cycle detection strictly raises `ValueError` if a node ID is revisited along the ancestor chain, cleanly mapped to `HTTP 422` by API routers.

3. **Same-Root Conservation & Chat Root Invariant:**
   - Branches remain descendants of the same root node.
   - An existing conversation root node cannot be demoted to a child branch (`HTTP 422 Unprocessable Content: Cannot attach an existing root conversation node to a parent`).
   - An existing branch cannot be migrated across different conversation roots (`HTTP 422 Unprocessable Content: Branch cannot be moved across different conversation roots`).
   - When a node is validly re-parented within the same root, the previous directed edge is pruned and the new directed edge is cleanly established.

4. **Source & Highlight Quote Validation:**
   - Highlighted quotes must not be empty or whitespace-only (`HTTP 422 Unprocessable Content: Highlighted quote cannot be empty or whitespace only`).
   - Highlighted quotes must not exceed 2000 characters (`HTTP 422 Unprocessable Content: Highlighted quote exceeds maximum length of 2000 characters`).
   - In ephemeral/standalone chat stream requests (`/api/v1/chat/stream`), focusing on a quoted excerpt requires an existing parent node or conversation context (`HTTP 422 Unprocessable Content: Highlighted quote requires a parent node`).

5. **Stale & Deleted Origin Handling:**
   - Branching from a deleted parent node (e.g. after branch pruning or conversation trimming) returns `HTTP 404 Not Found`.
   - Stale ephemeral parent references missing from client-provided trees return `HTTP 404 Not Found`.

6. **Continuation from User and Assistant Nodes:**
   - Both user and assistant nodes support branching.
   - Branching from an assistant node yields an assistant direct parent and appends the new user question.
   - Branching from a user node yields alternative user explorations and sibling branches without cross-contamination.

## 2. Changes Made

### 2.1 Backend Lineage & Ancestry Integrity (`packages/ai-core/src/ai_core/lineage.py`)
* Strengthened `get_ancestor_nodes(tree, node_id)`:
  - Validates `node_id` existence (`KeyError` if missing).
  - Traverses ancestor links with cycle detection (`ValueError` if cycle detected or depth exceeded).
  - Validates that parent nodes exist in tree (`KeyError` if broken parent pointer).
  - Validates that the ancestor path terminates at `tree.root_node_id` (`ValueError` if disconnected from root).
* Updated `resolve_conversation_lineage(tree, target_node_id, ...)` to propagate validation errors directly.

### 2.2 Workspace Service Node & Branch Integrity (`apps/api/src/services/workspace_service.py`)
* Updated `WorkspaceService.add_node_and_edge`:
  - Validates role against `{"user", "assistant", "system"}` (`HTTP 422`).
  - Strict parent lookup: rejects foreign workspace or missing parent with `HTTP 404`.
  - Self-loop cycle check (`data.id == data.parent_id` -> `HTTP 422`).
  - Ancestor traversal cycle check: prevents reparenting to descendants (`HTTP 422`).
  - Root protection: rejects demoting existing roots to child nodes (`HTTP 422`).
  - Root isolation: rejects moving branches across different conversation roots (`HTTP 422`).
  - Quote validation: rejects whitespace-only or oversized (>2000 char) quotes (`HTTP 422`).
  - Re-parenting edge maintenance: removes old edge and creates new edge when a branch is reparented within the same root.

### 2.3 Chat Router Lineage & Origin Authorization (`apps/api/src/routers/chat.py`)
* Added `from models.workspace import NodeModel`.
* Updated `ChatStreamRequest.validate_input` to validate `highlighted_context` (rejects empty/whitespace or >2000 chars).
* In `_verified_topic_context`:
  - When `workspace_id` and `parent_node_id` are provided without a tree, verifies that `parent_node_id` exists in the workspace and resolves the persisted ancestor lineage from the database.
  - When an ephemeral tree is provided, verifies that `target_id` and `root_node_id` exist in `tree.nodes`.
* In `_build_conversation_input`:
  - Rejects quotes without parent node or conversation context (`HTTP 422`).
  - Maps `KeyError` from lineage traversal to `HTTP 404` and `ValueError` to `HTTP 422`.

### 2.4 Branch Service Integrity Test Suite (`apps/api/tests/test_branch_integrity.py`)
* Implemented 16 comprehensive unit and integration tests covering all adversarial cases:
  1. `test_create_node_cross_workspace_parent_rejected`: Foreign workspace parent returns 404.
  2. `test_create_node_stale_or_nonexistent_parent_rejected`: Nonexistent parent returns 404.
  3. `test_create_node_deleted_origin_rejected`: Branching from deleted node returns 404.
  4. `test_create_node_direct_cycle_rejected`: Self-parenting returns 422.
  5. `test_reparent_node_descendant_cycle_rejected`: Reparenting to descendant returns 422.
  6. `test_reparent_root_node_to_parent_rejected`: Root demotion to child returns 422.
  7. `test_reparent_branch_to_different_root_rejected`: Cross-root branch migration returns 422.
  8. `test_create_node_invalid_role_rejected`: Invalid node role returns 422.
  9. `test_create_node_invalid_quote_empty_or_whitespace`: Empty quote returns 422.
  10. `test_create_node_invalid_quote_oversized`: Oversized quote returns 422.
  11. `test_chat_stream_cross_workspace_parent_rejected`: Cross-workspace stream parent returns 404.
  12. `test_chat_stream_stale_parent_rejected`: Stale stream parent returns 404.
  13. `test_chat_stream_ephemeral_cycle_rejected`: Ephemeral tree cycle returns 422.
  14. `test_chat_stream_ephemeral_stale_parent_rejected`: Ephemeral tree missing parent returns 404.
  15. `test_chat_stream_quote_without_parent_rejected`: Stream quote without parent returns 422.
  16. `test_continuation_from_user_and_assistant_nodes`: Seamless continuation from user and assistant nodes.
