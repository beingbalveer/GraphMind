## 1. Executive Summary & Objective

In accordance with [LSI-016](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-016-nested-branch-ui-and-canonical-navigation), the Learning Studio frontend has been equipped with first-class nested branch navigation, lineage breadcrumb reconstruction, sibling branch tab discovery, and URL handling:

1. **Lesson & Rail Visibility on Desktop:**
   - While a branch is active, the center lesson reader (`StudioLessonReader`) and the left course outline rail (`StudioCourseRail`) remain mounted and visible in `LearningStudioShell`.
   - The branch exploration is housed in the right contextual rail (`StudioTutorRail`), allowing learners to explore tangents without losing their place in the lesson.

2. **Lineage Breadcrumbs & Ancestry Reconstruction:**
   - When navigating to a branch node or deep-linking via `?node={nodeId}` or `?branch={branchId}`, the full ancestor chain is reconstructed using `reconstructBranchBreadcrumbs`.
   - The breadcrumb trail surfaces all branch divergence points from the topic trunk down to the active branch leaf.
   - Clicking any ancestor step in `BranchBreadcrumbs` navigates directly back to that branch or root conversation.
   - A dedicated "Main conversation" action returns to the topic trunk and clears the branch query state.

3. **Sibling Sub-Branch Switching:**
   - When multiple sibling branches stem from the same parent message or quote, `getSiblingBranchTabs` discovers and sorts them, rendering clean switchable tab pills ("Explain", "Code", "Compare", etc.).
   - Switching between sibling tabs preserves branch leaf context and updates the active leaf.

4. **Branching from Replies and Text Selection:**
   - Assistant messages in `StudioTutorChat` feature a "Branch from reply" / "Branch from selection" action.
   - Learners can highlight text inside an assistant message to branch directly from that excerpt, or click to branch from the full reply.
   - Initiating a branch mounts the branch origin quote in the composer with a clear context banner.
   - Sending the branch message creates a child node via `branchOverride: { parentNodeId, highlightedText }`.

5. **Canonical URL Navigation Invariants:**
   - Deep-linking uses `buildBranchUrl` (`/w/{workspaceId}/chat/{chatId}?branch={leafId}`) and `buildNodeUrl` (`?node={nodeId}`).
   - Primary navigation identifiers (`workspaceId` and `chatId`) remain strictly in path segments, **never in query parameters**.
   - `stripBranchParams` cleanly strips `?branch=` or `?node=` on branch close or Back navigation, preserving the root lesson/chat URL.
   - `parseBranchNavigation` safely parses branch and node parameters from `URLSearchParams`.

6. **Mobile Drawer & Accessibility:**
   - On viewports <1024px, the branch pane operates inside the responsive `<Drawer>` of `LearningStudioShell`, with proper accessibility labelling, focus handling, and Escape key dismissal.

## 2. Changes Made

### 2.1 Branch Lineage & Sibling Discovery Utilities (`apps/web/src/lib/branchUtils.ts`)
* Implemented `reconstructBranchBreadcrumbs`: Traverses the ancestor lineage from root to active node and generates `BreadcrumbStep[]` with human-readable titles.
* Implemented `getSiblingBranchTabs`: Discovers all sibling branch roots sharing the same parent context, identifies linear leaves via `getBranchLinearLeafNode`, and sorts pinned tabs first.
* Implemented `deriveBranchTitle`: Derives semantic labels ("Explain", "Code", "Compare", "Benchmarks", "Summary") from intent patterns, custom metadata titles, or highlighted text excerpts.
* Implemented `isNodeOnBranch`: Determines whether a given node is an ancestor of a branch divergence point.
* Implemented `getActiveBranchRoot`: Resolves the active divergence root node in a lineage.

### 2.2 Canonical URL Helpers (`apps/web/src/lib/urls.ts`)
* Updated `buildPublicLessonUrl` to accept optional `params?: { branch?: string; node?: string }`.
* Added `stripBranchParams(url: string)`: Strips branch and node parameters to retain canonical root URLs across back and refresh operations.
* Added `parseBranchNavigation(searchParams)`: Safely extracts `branchId` and `nodeId` from query parameters.

### 2.3 Studio Tutor Chat Branching Integration (`apps/web/src/components/studio/StudioTutorChat.tsx`)
* Added branch lineage banner with `BranchBreadcrumbs`, "Main conversation" return action, sibling sub-branch tabs, and quoted origin excerpt.
* Added "Branch from reply" and "Branch from selection" actions on assistant message footers.
* Added text selection mouse-up handler on assistant messages to isolate quoted excerpts.
* Added `activeBranchState` composer context banner for clear visual origin attribution.
* Added `onBranchChange` callback and auto-reconstruction for `initialBranchId` and `initialNodeId`.

### 2.4 Studio Tutor Rail & Preview Route Integration (`apps/web/src/components/studio/StudioTutorRail.tsx` & `apps/web/src/app/studio-preview/page.tsx`)
* Updated `StudioTutorRail` to forward `initialBranchId`, `initialNodeId`, `activeBranchLeafId`, and `onBranchChange` to `StudioTutorChat`.
* Updated `studio-preview/page.tsx` with `Suspense` boundary, `useSearchParams`, and `router.replace` synchronization.

### 2.5 Test Suites
* `apps/web/src/lib/__tests__/branchUtils.test.ts`: 8 unit tests verifying branch detection, multi-level ancestry breadcrumbs, sibling tabs, pinned sorting, and URL helpers.
* `apps/web/src/components/studio/__tests__/StudioNestedBranch.test.tsx`: 4 integration tests verifying:
  1. Desktop 3-column visibility (lesson reader, outline rail, branch rail simultaneously visible).
  2. Ancestry breadcrumbs reconstruction from deep link and return-to-main navigation.
  3. Branching from assistant message reply and text selection.
  4. Sibling branch tab switching.
