## 1. Executive Summary & Objective

In accordance with [LSI-017](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-017-standalone-workspace-chats), GraphMind now supports standalone, general-purpose workspace conversations fully decoupled from structured course/topic lessons:

1. **Clean Canonical URLs (No Message Text in URL):**
   - Initiating a new conversation from the Learning Studio rail or workspace modal immediately persists a parentless user root node and navigates directly to `/w/{workspaceId}/chat/{chatId}` using Next.js `router.push()`.
   - Message text is strictly transferred via POST body payload, **never in query parameters or URL hash**.

2. **Root Node Survival Across Refresh / Interruptions:**
   - If a conversation's assistant generation is interrupted or the browser reloads prior to the first response, the root user node survives intact in PostgreSQL.
   - The UI recovers the parentless root node, renders the saved question along with the recovery notice ("This saved conversation has no completed response yet."), and provides a single-click "Resume response" button that reuses the root with `preparedUserMessageId`.

3. **Topic & General-Chat Context Independence:**
   - Standalone chats do not send `topicSessionId` or leaked lesson metadata.
   - The backend strictly enforces this boundary:
     - Standalone roots have no `TopicChat` association (`topicChat=None`).
     - Forged or foreign `topicSessionId` payloads targeted at a standalone chat root are immediately rejected with HTTP 404.
     - Requests with `lessonStart: true` without a valid topic session are rejected with HTTP 422.
     - System prompts generated for standalone conversations contain 0 `SERVER-VERIFIED LEARNING CONTEXT` blocks.

## 2. Changes Made

### 2.1 Backend Contract & Verification (`apps/api/tests/test_standalone_chat.py`)
- Created comprehensive test suite verifying:
  - `test_create_standalone_root_node_contract`: Direct node creation via `POST /api/v1/workspaces/{ws_id}/nodes` with `parent_id=None`, retrieval in `GET /api/v1/workspaces/{ws_id}/chats` with `topicChat=None`, and graph snapshot retrieval with `nodes=[root]` and `edges=[]`.
  - `test_standalone_chat_stream_and_continuation_lifecycle`: Stream generation without topic lesson context leakage, assistant response node persistence, edge creation, and turn 2 continuation.
  - `test_standalone_chat_context_independence_and_forged_lesson_rejection`: Auth enforcement (401), rejection of foreign topic session IDs on standalone roots (404), and rejection of invalid `lessonStart: true` requests (422).
  - `test_standalone_root_survives_snapshot_and_resume_recovery`: Persistence and resume recovery of unresponded root nodes.

### 2.2 Studio Rail Integration (`apps/web/src/app/studio-preview/page.tsx`)

- Integrated `NewWorkspaceChatModal` with `buildChatUrl` on creation: navigates to `/w/{workspaceId}/chat/{rootNodeId}` with zero prompt text in the URL.
- Fixed `brief` property binding for `CurriculumItemData`.
