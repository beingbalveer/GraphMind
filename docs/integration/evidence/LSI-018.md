## 1. Executive Summary & Objective

In accordance with [LSI-018](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-018-course-directory-and-historical-chats), the Learning Studio now exposes a real course directory of historical conversations, built entirely on the existing chat metadata and authorization contract:

1. **Existing list/recent/pin/rename metadata reuse:**
   - The course directory lists a single authorized workspace's conversation trees from `GET /api/v1/workspaces/{workspaceId}/chats` (LSI-017 standalone roots plus LSI-013 topic tutor roots).
   - Pinned and recent ordering, titles, node counts, and topic associations are the server's existing values — no parallel store.
   - Rename and pin persist through the existing `PATCH /api/v1/workspaces/{workspaceId}/chats/{chatRootId}` contract, then refresh in place.

2. **Scoped search (`directory filter`):**
   - A scoped search box filters the projected directory by conversation title or lesson topic title.
   - The filter is workspace-scoped: only the authorized workspace's rows are ever projected (no cross-workspace rows).

3. **Branch ancestry projection:**
   - Each directory row projects its ancestry from existing metadata: `Lesson › {topic title}` for a topic tutor conversation, or `Personal` for an ordinary/standalone chat.
   - Selecting a conversation navigates through the canonical `buildChatUrl` (`/w/{workspaceId}/chat/{chatId}`), so the existing LSI-016 within-conversation branch ancestry (breadcrumbs, sibling branch tabs) renders in the chat/canvas view. Branches are never promoted to new chat roots.

4. **Outer ordinary/personal history access:**
   - Ordinary parentless chats (LSI-017) are surfaced alongside lesson chats with a `Personal` badge and opened through canonical URLs, so a learner can reach personal history from the directory.
   - The directory is workspace-agnostic and therefore reusable as the outer personal-history surface; no dead placeholder view was invented.

5. **History is not copied:**
   - The directory is a pure projection; a rename mutates the same root node's metadata. The project identity and row count are stable across refreshes, verified at the API boundary.

## 2. Changes Made

### 2.1 Directory Projection Helpers (`apps/web/src/lib/chatDirectory.ts`)
* Added `projectChatDirectory(chats, { excludeChatId })`: filters the protected structural row defensively, projects each chat into a `{ chat, kind, ancestry, pinned }` entry, and orders pinned-first then most-recently-updated, preserving the server order.
* Added `filterChatDirectory(entries, query)`: scoped search over title and lesson topic title.

### 2.2 Workspace Chat Client (`apps/web/src/lib/workspaceApi.ts`)
* Added `listWorkspaceChats(workspaceId, signal?)`: a strict variant of the tolerant `fetchWorkspaceChats` that rejects on failure so the directory can distinguish "no conversations" from "could not load" and offer retry. It is scoped to `/workspaces/{workspaceId}/chats`.
* Reused the existing `renameWorkspaceChat` and `togglePinWorkspaceChat` helpers unchanged.

### 2.3 Workspace Chat History Hook (`apps/web/src/hooks/useWorkspaceChats.ts`)
* Manages `chats`, `isLoading`, `loadError`, `actionError`, `refresh`, `renameChat`, and `togglePin` for one authorized workspace.
* Guards refreshes with an `AbortController` and a monotonic request id so a slower earlier response can never overwrite a newer workspace's list; reloads automatically when the workspace identity changes.

### 2.4 Course Directory Component (`apps/web/src/components/studio/StudioChatDirectory.tsx`)
* Renders the workspace directory with `Button`, `Input`, `Badge`, and `DropdownMenu` primitives from `@/components/ui` and semantic tokens only.
* Header (title, count badge, optional New chat), scoped search input, load/action error banners with retry, loading, no-conversations, and no-matches empty states.
* Each row shows the title, pinned indicator, `Lesson`/`Personal` badge, projected ancestry breadcrumb, an archived badge for archived topics, updated date, canonical open, inline rename, pin/unpin, and an "Open lesson" action for topic conversations.
* `excludeChatId` defensively omits the protected roadmap canvas anchor row.

### 2.5 Studio Preview Wiring (`apps/web/src/app/studio-preview/page.tsx`)
* Wired `StudioChatDirectory` into the course rail's Chats tab via the existing `chatsContent` prop.
* Opens conversations via `router.push(buildChatUrl(chat.workspaceId, chat.id))`; returns topic conversations to their lesson via the topic association. `excludeChatId` is the published canvas anchor.

### 2.6 Tests
* `apps/web/src/components/studio/__tests__/StudioChatDirectory.test.tsx` (7 tests): scoped listing with anchor exclusion, scoped search filter + clear, rename persistence, pin persistence/reordering, lesson-vs-personal ancestry projection, canonical open callback, and authorization failure + retry.
* `apps/web/src/hooks/__tests__/useWorkspaceChats.test.tsx` (8 tests): scoped mount load, no fetch without workspace, refresh, workspace-identity reload, rename success/failure, pin toggle, and load-error surfacing.
* `apps/api/tests/roadmap/test_course_directory.py` (4 tests): workspace scoping + anchor omission, rename/pin persistence and pinned-first ordering across repeated refreshes, unauthorized read/write rejection, and projection-without-copy (stable row ids across refresh and rename).
