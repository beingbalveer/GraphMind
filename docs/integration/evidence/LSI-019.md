## 1. Executive Summary & Objective

In accordance with [LSI-019](file:///Users/balveerd/Documents/AI/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-019-rich-replies-and-agent-tools), the Learning Studio AI Tutor pane now renders the same rich replies as the main conversation, reusing the existing renderers and message actions instead of a plain-text bubble:

1. **Shared Rich Renderers:**
   - Assistant replies in `StudioTutorChat` render through the existing `MarkdownRenderer` (Markdown + GFM + KaTeX math + `rehype-highlight` code blocks + inline branch links + the fenced `quiz` card).
   - Agent tool activity renders through the existing `AgentToolCallsBanner`, so `running` / `completed` / `error` states and failed-action alerts are visible.
   - Grounded RAG citations render through a newly extracted, shared `RagSourcesStrip`; selecting a citation opens the real snippet `Modal` or `PdfViewerModal` (PDF page deep link via `resolveFileUrl`).
   - Failed replies surface the existing destructive error styling and retry affordance.

2. **Unsafe Markup & Link Policy:**
   - `MarkdownRenderer` explicitly pins `urlTransform={defaultUrlTransform}`, locking the react-markdown safe-link contract so `javascript:`, `data:`, `vbscript:` and similar protocols are stripped before the anchor renderer runs; raw HTML is never mounted as live DOM.

3. **Incremental vs. Final Content:**
   - `useChatStream` accumulates each streamed `content` delta and the final assistant node content is exactly the concatenation of those deltas; the rendered final reply therefore agrees with the incremental stream.

4. **Reuse, Not New Capability (Zero Dead UI):**
   - No new agent tools were invented. The tutor pane only wires up renderers/actions that already map to live services (`MarkdownRenderer`, `AgentToolCallsBanner`, `RagSourcesStrip`, PDF/snippet viewers, and the existing copy/branch/retry/stop actions).

## 2. Changes Made

### 2.1 Extracted Reusable Citations Strip (`apps/web/src/components/chat/RagSourcesStrip.tsx`, new)
- Extracted the grounded RAG "Verified sources" collapsible strip out of `ChatMessage` into a standalone, reusable component with a typed `RagSourceItem` and an `onSelectSource` callback.
- Preserves the existing interaction contract: collapsed by default, `Verified sources` count badge, per-source filename buttons, and a `p. {page}` badge.

### 2.2 Rich Reply Wiring in the Tutor Pane (`apps/web/src/components/studio/StudioTutorChat.tsx`)
- Assistant message bodies now reuse `MarkdownRenderer` (Markdown / KaTeX / code / quiz / error), `AgentToolCallsBanner` (tool events + failures), and `RagSourcesStrip` (citations).
- Added `viewingRagPdf` / `viewingRagSnippet` state and `handleSelectRagSource` to open the real `PdfViewerModal` / snippet `Modal`.
- Retained all existing tutor actions: copy, branch from reply/selection, retry, stop, quoted-passage/branch banners, and the reduced-motion streaming caret. User messages remain plain text.
- Applied destructive error styling when a reply holds the `⚠️ **Error:**` marker.

### 2.3 Shared Renderer Hardening (`apps/web/src/components/chat/ChatMessage.tsx`)
- Pinned `urlTransform={defaultUrlTransform}` on `ReactMarkdown` to lock the safe-link contract.
- Replaced the inline RAG strip with `<RagSourcesStrip>` and removed now-unused `Badge` / `Collapsible` imports and `areSourcesOpen` state. `RagSourceItem` now comes from the shared module and is re-exported for backward compatibility.

### 2.4 Focused Tests
- `apps/web/src/components/chat/__tests__/rich-replies-lsi019.test.tsx` (5 tests): SSE incremental-vs-final content parity via a controlled `ReadableStream`; unsafe `javascript:` / `data:` link and raw HTML injection blocking; safe external link preservation with `noopener`; reused quiz and fenced-code renderers.
- `apps/web/src/components/studio/__tests__/StudioTutorRichReplies.test.tsx` (5 tests): tutor markdown rendering, visible agent tool failure, grounded citation → real snippet viewer, retained copy/branch actions, retained retry action.
