## 1. Executive Summary & Objective

In accordance with [LSI-020](file:///Users/balveer/Projects/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-020-generator-request-and-provenance-extensions), the existing generator request contract was mapped and extended with **only** the approved optional fields from [LSI-002 §7](./LSI-002.md#7-generator-request-extensions):

1. **Additive, backward-compatible schema.** `RoadmapRequest` gained four optional fields — `outcome`, `known_skills`, `reference_url`, and `sample_template_ref` — that mirror the prototype's `outcome`, `knownSkills`, `referenceUrl`, and `sampleTemplateRef`. A request that supplies only the pre-existing fields (`title`, `prompt`, `level`, `background`, `duration`, `hoursPerWeek`) validates and behaves exactly as before. Note: the authoritative `RoadmapRequest` lives in `apps/api/src/schemas/curriculum.py` (not `roadmap_jobs.py` as LSI-002 §7 abbreviates), so the extension was applied there.

2. **Unsupported fields are rejected, never dropped.** `RoadmapRequest` inherits `CurriculumSchema` (`extra="forbid"`), so any unknown field fails with HTTP `422 VALIDATION_ERROR`. The four approved fields are declared on the canonical request model and therefore survive the full job lifecycle (canonical hash → `roadmap_jobs.request` JSON → `JobSnapshot.request`), so supported input is never silently discarded.

3. **Sources validated with existing protections.** The optional reference URL is normalized through the existing `services/roadmap/source_fetcher.canonical_source_url` guard (scheme/host/port allowlist, no credentials, no localhost/private addresses, ≤2048 characters), the same protection the reference-attachment route already uses. The optional sample-template snapshot reference is validated against the currently approved sample snapshots; unknown or superseded references fail loudly instead of being ignored.

4. **Explicit error responses.** Semantic extension failures return the standard structured `RoadmapHTTPError` envelope with stable codes (`URL_BLOCKED`, `SAMPLE_TEMPLATE_INVALID`, `SAMPLE_TEMPLATE_UNKNOWN`, `SAMPLE_TEMPLATE_STALE`) rather than a generic error.

## 2. Changes Made

### 2.1 Generator request schema (`apps/api/src/schemas/curriculum.py`)
* Extended `RoadmapRequest` (additive, `extra="forbid"` preserved) with:
  * `outcome: str | None = Field(default=None, max_length=2000)`
  * `known_skills: list[str] = Field(default_factory=list, max_length=50)`
  * `reference_url: str | None = Field(default=None, max_length=2048)`
  * `sample_template_ref: str | None = Field(default=None, max_length=100)`
* Extended the existing `optional_text` before-validator to blank-normalize `outcome`, `reference_url`, and `sample_template_ref` into `None`.
* Added a `known_skills` validator that trims each skill and bounds each label to 120 characters.

### 2.2 Profile normalization (`apps/api/src/services/roadmap/workload.py`)
* Updated `normalize_profile` to build `LearningProfile` from `request.model_dump(exclude={"outcome"})` and `outcome=request.outcome or request.prompt`. This preserves the prior behavior (`outcome` defaults to the prompt) while allowing the new optional `outcome` to override it, and avoids a duplicate-keyword collision introduced by the additive base field.

### 2.3 New validation service (`apps/api/src/services/roadmap/generator_request.py`)
* `GeneratorRequestError(code, message)` — structured error for extension failures.
* `SampleTemplate` dataclass and `CURATED_SAMPLE_TEMPLATES` — the three approved preview snapshots (`roadmap-python-backend`, `roadmap-web-accessibility`, `roadmap-sql-queries` @ `2026-10-14.1`). This allowlist is the documented boundary that LSI-025 replaces with the published snapshot table.
* `resolve_sample_template(ref, available=None)` — accepts `template_id` or `template_id@snapshot_version`; raises `SAMPLE_TEMPLATE_INVALID`, `SAMPLE_TEMPLATE_UNKNOWN`, or `SAMPLE_TEMPLATE_STALE`.
* `normalize_reference_url(url)` — reuses `canonical_source_url` and the 2048-character bound.
* `extend_generator_request(request, available=None)` — validates/normalizes the optional fields and returns the request to persist.

### 2.4 API boundary (`apps/api/src/routers/roadmap_jobs.py`)
* `POST /api/v1/roadmap/jobs` now runs `extend_generator_request` before creating the job and converts `GeneratorRequestError` into an explicit `RoadmapHTTPError(422, JobError(...))` with `next_action="new_run"`.

### 2.5 Focused test suite (`apps/api/tests/roadmap/test_generator_request.py`)
* 28 tests covering schema/backward-compatibility, extension bounds, unknown-field rejection, URL-bounds, canonicalization, stale/unknown/malformed sample sources, persisted round-trip through `JobRepository`, and the API boundary (acceptance + explicit rejection).

## 4. Ticket Status Transition & Limitations

* **Transition:** `TODO` → `IN_PROGRESS` → `VERIFYING`. All scope and acceptance criteria are implemented and verified. Per the integrating session's instruction, this ticket did **not** run `git add`/`commit`/`push` and did **not** edit the shared backlog board (`docs/integration/LEARNING_STUDIO_BACKLOG.md`) or `HANDOFF.md`; the final `VERIFYING` → `DONE` transition and completion commit (with this evidence) are the integrating session's step.
* **Limitations / explicit boundaries:**
  * `CURATED_SAMPLE_TEMPLATES` is a deliberate interim allowlist because public snapshot storage is LSI-025 scope. Until LSI-025 lands, `sample_template_ref` values outside the three approved snapshots are rejected as unknown/stale. LSI-025 replaces the allowlist with the published snapshot table without changing this request contract.
  * Only the generator-request API boundary (`POST /roadmap/jobs`) performs URL/sample validation; internal callers that construct a `RoadmapJob` directly through `JobRepository` retain schema-level bounds but not the semantic checks.
  * The additive `reference_url`/`sample_template_ref` fields now flow into `LearningProfile` (via `normalize_profile`) and are therefore persisted in the checkpoint profile, but no publishing/provenance projection (e.g. `sourceSnapshotRef` on the roadmap profile) was added here; that belongs to LSI-022/LSI-025/LSI-028.
