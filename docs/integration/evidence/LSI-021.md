## 1. Executive Summary & Objective

In accordance with [LSI-021](file:///Users/balveer/Projects/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-021-goal-form-and-profile-review), the Learning Studio generator front end now maps real inputs onto the LSI-020 `RoadmapRequest` extensions (`outcome`, `knownSkills`, `referenceUrl`, `sampleTemplateRef`), validates them against the server bounds, and presents an editable review followed by an immutable submitted snapshot.

1. **Real inputs, not a fixed sample.** A new pure mapping module (`generatorProfile.ts`) turns an editable draft into the extended request. The goal itself is sufficient for real generation; `sampleTemplateRef` is optional and empty by default. The prototype's requirement to pick a fixed sample curriculum is removed.
2. **Server-aligned validation.** Client bounds mirror `apps/api/src/schemas/curriculum.py` (goal 10–8000, title ≤180, background ≤4000, outcome ≤2000, known skills ≤50 items ×120 chars, reference URL ≤2048 and public-http(s)-only, hours 0.5–80 in half-hour steps, duration 1–104 whole weeks).
3. **Editable review → immutable submitted profile.** `StudioGoalForm` walks a two-step flow. "Review details" derives practical title/outcome defaults from the goal and freezes a snapshot; the review renders that snapshot read-only. A failed submission keeps both the learner's edits and the submitted snapshot, with an explicit "Back and edit" recovery.
4. **Sample-copy path is clearly separate.** Creation paths are a segmented choice: "Generate from my goal" (default, no sample) versus "Copy a sample roadmap" (distinct section, approved allowlist, distinct "Sample copy" badge and content-source copy). Real generation never requires a sample.
5. **Approved preference defaults.** A blank draft is seeded from approved, bounds-sanitized preference defaults (level, hours per week, duration in weeks), so a stored `default_study_hours`-style value flows in without breaking the schema.

## 2. Changes Made

### 2.1 Goal-form mapping and validation (`apps/web/src/lib/generatorProfile.ts`, new)
* `GeneratorProfile` draft type (goal, title, level, outcome, known skills, background, reference URL, sample ref, hours, duration) plus `SampleTemplateOption`.
* `APPROVED_SAMPLE_TEMPLATES` — the three curated snapshots (`roadmap-python-backend`, `roadmap-web-accessibility`, `roadmap-sql-queries` @ `2026-10-14.1`) mirroring the LSI-020 backend allowlist; used only by the sample-copy path.
* `APPROVED_GENERATOR_DEFAULTS` + `approvedProfileDefaults()` + `createBlankProfile()` — approved preference defaults, sanitized back to bounds (out-of-range or non-half-hour/fractional preferences fall back to the approved default).
* `isHttpUrl()` — mirrors the public-source URL guard (http/https, host required, no credentials, ≤2048).
* `deriveProfileDefaults()` — auto-derives title/outcome from the goal without clobbering explicit edits.
* `validateProfile()` — per-field errors matching the server bounds.
* `buildRoadmapRequest()` — maps the draft onto the extended `RoadmapRequest` (camelCase), emitting `null`/`[]` for unset optional fields.

### 2.2 Extended request contract (`apps/web/src/lib/roadmapTypes.ts`)
* Added the additive LSI-020 fields to `RoadmapRequest`: `outcome`, `knownSkills`, `referenceUrl`, `sampleTemplateRef` (all optional). Backward compatible with existing callers.

### 2.3 Goal form and profile review component (`apps/web/src/components/studio/StudioGoalForm.tsx`, new)
* Two-step form → review flow; segmented "generate" vs "sample" path; optional details collapsible (outcome, known-skill tag editor, background, reference URL, hours, duration).
* Immutable review card (`data-testid="studio-goal-form-review"`) with a path badge ("New generation" / "Sample copy") and an explicit content-source card that separates the two paths.
* Failure handling: an `onSubmit` rejection shows an inline alert while retaining the draft and submitted snapshot; "Back and edit" returns to the editable form with values intact.
* Strict `@/components/ui/` primitives (`Button`, `Input`, `Textarea`, `Badge`, `SegmentedTabs`, `Collapsible`), semantic tokens, standard type scale; no raw `<button>` or arbitrary `text-[..]`.

### 2.4 Minimal preview mount (`apps/web/src/app/studio-preview/page.tsx`)
* Surgical: "Create" navigation now exits the course context and renders `StudioGoalForm` on the gated internal preview route. The `onSubmit` is a clearly-commented preview stub; the real owned job-creation flow is LSI-022 scope.

### 2.5 Focused test suite
* `apps/web/src/lib/__tests__/generatorProfile.test.ts` (13 tests): defaults, mapping, bounds, URL guard, shared-fields.
* `apps/web/src/components/studio/__tests__/StudioGoalForm.test.tsx` (5 tests): form mapping, immutable review, failure-retains-edits, validation gating, separate sample path, preference defaults.
