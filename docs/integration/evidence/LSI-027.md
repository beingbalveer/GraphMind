## 1. Executive Summary & Objective

In accordance with [LSI-027](file:///Users/balveer/Projects/GraphMind/docs/integration/LEARNING_STUDIO_BACKLOG.md#lsi-027-public-snapshot-and-lesson-api), this change exposes the **anonymous, versioned public roadmap/lesson reads** over the immutable snapshots frozen by LSI-025. It implements the two guest routes assigned to LSI-027 in the LSI-001 endpoint map ([LSI-001 §API surface](./LSI-001.md)):

* `GET /api/v1/public/roadmaps/{slug}` → `PublicRoadmapDetail`
* `GET /api/v1/public/roadmaps/{slug}/topics/{topicSlug}` → `PublicLessonDetail`

The catalog *list* endpoint (`GET /api/v1/public/roadmaps`) is LSI-026 and is intentionally left to a separate router and file.

Design decisions:

1. **Uniform, neutral unavailability.** Missing templates, unknown/stale pinned versions, unknown topics, and unpublished content all collapse to a single structured `404` with the message `"This content is not available."`. The requested reference is never echoed, so an anonymous caller cannot distinguish "never existed" from "withdrawn" and learns nothing about private origins.
2. **Versioned reads without moving the URL.** The URL stays anchored to the stable public `slug` (LSI-002 §3.2). An optional `version` query pins a frozen `snapshot_version`; when omitted, the newest published version is resolved deterministically. A pinned older release remains readable and its public IDs are stable across releases, because LSI-025 derives public identities from `(template_id, private_id)`, not from the version.
3. **Identity-independent serialization.** Guest, signed-in, and outsider callers receive byte-identical payloads, because the routes depend only on the request-scoped DB session and read the same vetted DTOs. No auth dependency, no workspace header, no user context.
4. **Safe public sources.** In addition to LSI-025's curation (unavailable/unreferenced sources dropped, provenance stripped), the router strips any non-`http(s)` source location (e.g. `javascript:` / `data:` URIs) to `None` as defense in depth, so a guest browser can never be handed a hostile link.
5. **Never cache availability.** Responses carry `Cache-Control: no-store`, so a previously published body can never be replayed from a cache after the snapshot is unpublished.

## 2. Changes Made

### 2.1 Public snapshot/lesson router (`apps/api/src/routers/public_snapshots.py`) — NEW
* `APIRouter(prefix="/public", tags=["Public learning"])`, registered in `main.py` under the `/api/v1` prefix.
* `GET /public/roadmaps/{slug}` (optional `version` query) → `PublicRoadmapDetail`.
* `GET /public/roadmaps/{slug}/topics/{topic_slug}` (optional `version` query) → `PublicLessonDetail`; resolves the topic against both the frozen public slug and the stable opaque public topic id.
* Single neutral `_unavailable(...)` factory: `HTTPException(404, "This content is not available.")`, routed through the repo's existing structured error envelope (`{"error": {code, message, request_id}}`).
* `_safe_source` / `_safe_sources`: `http`/`https`-only URL projection over `PublicSourceReference` (nulling anything else).
* `Cache-Control: no-store` on every read.
* No new dependency, no auth override, no private field access; only the public DTO builders from `PublicSnapshotService` are used.

### 2.2 Router registration (`apps/api/src/main.py`)
* Added `public_snapshots,` to the `from routers import (...)` list.
* Added `app.include_router(public_snapshots.router, prefix="/api/v1")` immediately after the `files.router` include. (The concurrently authored LSI-026 `public_catalog.router` include remains present and untouched; both share the `/api/v1/public/roadmaps` prefix without route collision — LSI-026 owns the collection path, LSI-027 owns the `{slug}` detail/lesson paths.)

### 2.3 Focused tests (`apps/api/tests/roadmap/test_public_snapshot_api.py`) — NEW
7 tests exercising the HTTP boundary against the isolated `_test` database:
1. `test_guest_reads_stable_public_roadmap_and_lesson` — guest 200s; `pub_topic_`/`pub_src_` IDs; byte-stable across reads; lesson reachable by public slug and by opaque public topic id.
2. `test_versioned_read_pins_immutable_version_across_releases` — newest-by-default; pinned older version readable; public topic IDs identical across versions.
3. `test_guest_signed_in_and_outsider_serialize_identically` — guest == owner (signed-in) == outsider payloads for detail and lesson; forbidden-token + workspace/revision/user-id scans.
4. `test_missing_and_stale_content_share_one_neutral_response` — unknown template, stale/unknown version, unknown topic, unknown-template lesson all return the same neutral `404`; valid content still 200.
5. `test_unpublish_withdraws_reads_and_is_never_cached` — `Cache-Control: no-store`; after `unpublish`, detail, lesson, and pinned-version reads are neutral `404` (no replay).
6. `test_unsafe_source_urls_are_neutralized` — an injected `javascript:` source URL is returned as `null` on both detail and lesson.
7. `test_public_snapshot_router_routes_are_registered` — both routes are present in the app's OpenAPI paths.

### 2.4 No migration, no shared-router touch
* No alembic migration added (LSI-025's `20261015_0007` tables/indexes already exist).
* `apps/api/src/routers/public_catalog.py` (LSI-026, concurrently authored) was not modified.
