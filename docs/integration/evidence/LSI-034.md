## 1. Executive Summary & Objective

[LSI-034](../LEARNING_STUDIO_BACKLOG.md#lsi-034-existing-modal-viewers) is an **Epic E (Legacy parity)** frontend ticket: *preserve* the already-exposed PDF / code / table (CSV, TSV, Excel, JSONL) viewers, keep them on the shared modal primitives, and prove correct file/content/**source-locator** behaviour, supported **large-table** behaviour, and **nested-modal Escape/focus** with **safe downloads**.

The three viewers already existed and were already reused across every file surface — `FileLibraryView`, `FileLibraryModal`, `ChatMessage` (attachments + RAG citations), and `StudioTutorChat`. They are wrapped in the shared `Modal` primitive and built from `Button` / `SegmentedTabs` / `Badge` / `Input`. This ticket therefore:

1. **Verified and preserved** the viewers, their invocation sites, and the `resolveFileUrl` workspace-scoped download path. No new file format or bespoke dialog was added.
2. **Fixed two real acceptance gaps found by test** (see §3): the shared `Modal` primitive suppressed focus for input-less dialogs, and the library's image preview was a bespoke `fixed` overlay with no Escape/focus handling.
3. **Added focused vitest evidence** covering the viewer fixtures, error/empty states, the large-table page matrix, the source locator, safe downloads, and nested-modal keyboard/focus behaviour.

## 3. Changes Made

Runtime changes are intentionally small and confined to the viewer modal surface.

### 3.1 Shared primitive — `apps/web/src/components/ui/modal.tsx` (1 line)
- `initialFocus` now falls back to `null` instead of `false` when the popup has no `input`/`textarea`/`select`:
  `…querySelector(...) ?? null`.
- **Root cause:** Base UI only applies its default focus behaviour for `null`/`true`; returning `false` *suppresses* focus. Because the viewers have no form input, opening a viewer (especially **nested** on the library modal) left focus on the parent instead of moving it into the dialog — a nested-modal focus defect and an ARIA violation.
- **Effect:** input-less dialogs now receive focus on open (first tabbable, per ARIA); dialogs with an input are unchanged.

### 3.2 Ad-hoc overlay removal — `apps/web/src/components/library/FileLibraryModal.tsx`
- The full-resolution image lightbox was a hand-rolled `fixed inset-0 z-60` overlay with no Escape and no focus management. It is now a shared primitive modal: `<Modal>` + `<ModalHeader>` + `<ModalBody>` + `<ModalFooter>` (AGENTS.md §5 Rule 1). Download stays workspace-scoped.

### 3.3 New tests — `apps/web/src/components/chat/__tests__/viewer-modals.test.tsx` (14 tests)
- **Code:** content/language/lines; Markdown Preview↔Source; Escape; clipboard copy; URL and Blob download paths.
- **PDF:** iframe + `#page=4` locator + `Page 4` badge; `?download=true` attachment download; explicit "Unable to load PDF preview." error state.
- **Table:** CSV row/column metadata; **large-table 120-row pagination at 50/page** (`1 / 3` → `2 / 3`, `Showing 51–100 of 120 rows`); search filter + numeric sort; JSONL column union; XLSX extracted-Markdown with `Sheet: Q1` locator; empty-state + Escape.
- **Nested modals:** library → PDF viewer moves focus into the viewer and Escape closes **only** the top viewer; library → image lightbox primitive modal likewise.
