## 5. Membership / authorization evidence

* `require_workspace_read` returns **404** for non-members/unknown workspaces;
  `require_workspace_write` returns **404** for non-members and **403** for
  viewers — never data. Every workspace-scoped route uses one of them (grep-verified
  across `workspaces.py`, `roadmap*.py`, `curriculum.py`, `canvas.py`,
  `flashcards.py`, `files.py`, `mastery.py`, `curator.py`).
* `apps/api/tests/test_workspace_rbac.py` proves cross-tenant isolation (a second
  user cannot list, read, write, or delete another's workspace).
* `apps/api/tests/test_workspace_export.py::test_workspace_export_requires_membership`
  proves a non-member cannot export another workspace.

### 5.1 Resolved review finding — anonymous workspace listing (fixed)

The independent review found a real cross-tenant leak: `GET /api/v1/workspaces`
used `get_optional_user`, and `WorkspaceService.list_workspaces` applied **no
owner filter when `user_id is None`**, so an anonymous/invalid caller received
every tenant's workspace metadata (name, description, viewport, node counts,
curriculum summaries). `get_optional_user` silently downgraded an invalid token
to `None`, and the test-mode default-admin fallback hid the anonymous path.

**Fix (this commit):**
* `apps/api/src/routers/workspaces.py` — `list_workspaces`, `create_workspace`,
  and `seed_demo_workspace` now depend on `get_current_user` (authentication
  required; no anonymous enumeration or writes attributed to a shared account).
* `apps/api/src/services/workspace_service.py` — `list_workspaces` returns an
  empty authorized collection `([], 0)` when there is no identity
  (defense-in-depth), and the query always filters by owner/membership.
* `apps/api/tests/test_workspace_listing_access.py` — an invalid credential now
  yields `401` for list/create/seed (this fails on the pre-fix code), the service
  lists nothing without an identity, and listing stays scoped per user.

**Actual Result:** `3 passed` (the invalid-token assertions would have returned
200/all-rows before the fix).

## 6. Public DTO / auth-intent security evidence
